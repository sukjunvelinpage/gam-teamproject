## 4. 평가 기준 (절대평가, Q&A 점수 합산 전)

| 등급 | 기준 | 점수 |
| :--- | :--- | :---: |
| **Excellent** | 조금만 다듬으면 증권사 리포트 수준으로 발전 가능한 정도 이상 | 18점 |
| **Good** | 대학생 수준에서 꽤 참신하거나 정교한 정도 | 15점 |
| **Normal** | 전형적인 대학 수업에서 기대되는 보통 정도 | 12점 |
| **Poor** | 발표 취지에 맞지 않거나, 논리가 없거나, 기존 문헌을 짜깁기한 정도 | 8점 |

- 매년 Excellent는 0~2팀, Poor는 0~1팀 정도였습니다.
- **인원 가산점:** 2인 조 +2점, 3인 조 +1점
- 학생에게는 Q&A 점수까지 합산한 **총점만** 공개되며, 발표 등급은 알려주지 않습니다.
- **Excellent를 받은 조는 공개 발표**를 하게 됩니다 (조사·연구·발표의 스탠다드를 보여주기 위함).
