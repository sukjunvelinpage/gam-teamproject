# 분석 입력 파일 안내

작성일 2026-11-03. 사용자의 결정에 따라 추가 분류를 중단하고, 현재까지의 기존 분류와 검토·복원 결과를 분석 입력용으로 정리했다. **결측은 0이나 부정·중립이 아니다.**

## 파일 구성

`data/trump_tweets_analysis_input.csv`는 원자료 26,239개 게시물의 원문, 기존 분류, 추가 검토·복원 기록과 보수적 판단을 행 단위로 모았다. 원본 행 번호 `raw_row`는 0부터 시작하며 `audit_key`와 함께 연결을 검증했다. 1행이 하나의 원자료 게시물이며 동일 사건의 여러 게시물은 아직 별도 사건으로 통합되지 않았다.

`data/trump_market_analysis_input.csv`는 기존 시장 자료 1,007거래일·120열을 그대로 보존하고, 보수적 기준의 잠정 사건과 미확정 게시물이 해당 날짜에 있을 가능성을 별도 열로 덧붙였다. 기존 열과 새 열을 혼동하지 않는다. 기간 T, T+1, CAR[0,+1], CAR[0,+2]의 통계 결과를 새로 산출하지 않았다.

## 기존 분류와 추가 후보

`legacy_signal`과 `legacy_subtype`은 기존 1,246건의 분류를 그대로 보존한다. 긍정 357, 부정 421, Noise 468건이다. 나머지 글은 기존 분류 대상이 아니므로 이 열이 빈칸이다. 빈칸을 Noise 또는 무신호로 취급하면 안 된다. 원래 분류의 목적과 기준이 새 보수적 기준과 다르므로 새 기준의 최종 부호로 읽어서는 안 된다.

추가 후보의 원문과 이전 검토 결과는 `additional_status`, `additional_themes`, `additional_direction`, `additional_reason_ko` 및 `restore_` 열에 남아 있다. 기존에 분석한 1,246건 외의 **새로운 핵심 포함 확정 글은 0건**이다. 구체적 조치로 잠정 선정된 2건 R24641과 R5605는 모두 기존 1,246건에 이미 들어 있어 중복 추가하지 않았다.

## 보수적 무역·관세 열

- `strict_review_state`: `excluded_core`는 핵심 범위에서 잠정 제외, `hold`는 판정 보류, `not_reviewed_under_conservative_standard`는 새 보수 기준의 개별 기록 없음, `provisional_include`는 잠정 핵심 후보다.
- `strict_provisional_flag`: `1`은 잠정 후보 2건, `0`은 보수적 핵심 잠정 제외 2,616건, 빈칸은 보류·미검토 23,621건이다. 이것은 확정 포함 변수가 아니다.
- `strict_confirmed_flag`: 확정 기준의 최종 사건 분류가 없어서 전부 빈칸이다.
- `strict_direction`: 잠정 포함 2건의 무역갈등 방향만 기록했다. 다른 글의 방향은 빈칸이다. 기존 긍정·부정을 이 방향으로 자동 변환하지 않았다.
- `strict_reason_ko`: 기존 검토의 판단 근거. `strict_evidence_count`는 검토 원장에서 확인 가능한 자료의 수이며 자료의 정확성이나 신규성의 확정 증거가 아니다.

## 시각과 거래일

저장 UTC와 ID에서 근사한 UTC가 충돌하는 311행은 `trading_date`를 빈칸으로 두었다. 양 시각에 따른 가능 거래일은 `stored_time_trading_date_candidate`와 `id_time_trading_date_candidate`에 각각 보존했다. ID의 하위 자릿수가 손상되어 ID 시각도 근사치이며, 이를 완벽한 원래 ID로 해석해서는 안 된다. 실제 NYSE 폐장시각, 조기 폐장·주말·휴일을 반영하고 폐장 시각의 게시물은 다음 거래일에 연결한다. 폐장 경계 ±2초는 보류한다.

잠정 사례 R24641은 2019-05-06, R5605는 2019-12-02 거래일로 연결된다. 시장 자료의 시간과 해당 일별 수익률은 트윗 게시 이전의 가격 움직임을 포함할 수 있으므로 같은 날 수익률을 순수한 사후 반응으로 해석하지 않는다.

## 거래일별 분석 시 주의

`strict_provisional_known_count`는 해당 거래일에 매핑된 잠정 후보의 수다. `strict_unresolved_possible_count`는 보류·미검토이거나 시각이 불명확한 글이 해당 거래일에 속할 가능성이 있는 건수다. 시각 충돌 시 저장 시각과 ID 근사 시각의 양쪽 후보 날짜를 사용한다.

`strict_provisional_event`는 잠정 후보가 있을 때 1, 잠정 후보와 미확정 가능성이 모두 없을 때만 0, 나머지는 빈칸이다. 사건일 2일도 다른 미확정 게시물을 포함할 수 있다. `strict_confirmed_event`는 전부 빈칸이다. 현재 1,007거래일 중 잠정 사건 1은 2일, 잠정 0은 15일, 나머지 990일은 빈칸이다. 미확인 게시물을 무신호로 취급하지 않으면 **보수적 기준의 확정 사건·대조군 비교는 현재 자료만으로 적절하게 수행할 수 없다.**

기존 시장 파일의 `Policy_*`, `Trade_*`, `Fed_*` 등 열은 기존 기준의 집계로서 과거 결과를 재현하는 탐색적 비교에 사용할 수 있으나, 위 보수 기준을 재적용한 결과가 아니다. 사건 수가 2개뿐인 보수적 잠정 표본은 연구 결과를 확정할 만큼 충분하지 않다. 일별 거래일 대조에서 자료가 없는 값을 0으로 바꾸거나 완전 사례만 남겨 표본 선택 사실을 숨기지 않는다.

## 재생성과 무결성

`python scripts/build_analysis_ready_tweet_data.py`를 실행하면 두 파일과 `analysis_input_summary.json`을 생성한다. 원자료·분류 원장·시각 원장·시장 자료의 해시를 요약에 기록한다. CSV에서 숫자형 게시물 ID는 엑셀에서 반올림될 수 있으므로 연결에는 `raw_row`와 `audit_key`를 사용한다. 기존 입력 파일은 수정하지 않는다.
