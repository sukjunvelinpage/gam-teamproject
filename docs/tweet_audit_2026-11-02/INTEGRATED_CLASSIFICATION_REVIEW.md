# 확정 연구 범위에 따른 통합 분류와 추가 검토

작성일: 2026-11-03. 이 문서는 트럼프의 경제·정책 관련 트윗과 시장 전체·산업·기업·글로벌 자산의 관계를 살펴보는 연구 범위에 맞춘 작업 기록이다. 무역·관세를 중심 분석, 통화정책·기업·재정은 별도 유형으로 검토한다.

## 현재 상태와 한계

`data/trump_policy_tweets_integrated_review.csv`는 원자료 26,239행을 하나의 행 단위 원장으로 연결한 **검토용 잠정 통합본**이다. 기존 분류 1,246행, 이전 추가 검색 검토 437행, 나머지 검토 24,556행은 서로 겹치지 않으며 모두 보존했다. 기존 긍정·부정, 신규 후보 판정, 판정 이유, 외부 복원 내용과 시각 경고를 독립된 열에 남겼다.

이번에 51행의 새 판단을 기록했다. 기존 감사·복원 사례 11행과 이전 광의 후보의 포괄 범주에서 선택한 40행이다. 이 40행은 무작위 표본이 아니며 전체 후보의 오류율을 추정할 수 없다. 40행의 잠정 결과는 포함 후보 8, 경제 성과 평가 7, 제외 13, 문맥 필요 12다. 예전에 광의 후보였던 R1285는 국방수권법에 관한 정치적 수사, R1296은 허리케인 경보로 경제정책 조치가 본문에 명시되지 않았다. 반면 R1288은 주가 최고치에 대한 사후 평가이므로 정책 발표와 별도로 보존했다. 그 외 포괄 범주의 968건과 다른 후보들은 새 범위에 따라 개별 확정하지 않았다.

| 통합 상태 | 행 수 | 의미 |
|---|---:|---|
| provisional_exclude | 16,645 | 이전 또는 이번 검토에 따른 잠정 제외; 확정 정답 아님 |
| candidate_needs_scope_review | 4,352 | 경제·정책 관련 후보. 확정 포함 아님 |
| context_required | 3,638 | 추가 원문 또는 연결 자료 필요 |
| existing_label_needs_scope_review | 1,239 | 기존 분류는 있으나 새 기준 적용 확인 필요 |
| review_required | 358 | 기존 검색에서 포함·제외가 결정되지 않음 |
| performance_commentary | 7 | 이번에 개별 확인한 경제 성과 평가; 신규 조치와 별도 취급 |
| 합계 | 26,239 | 상호 배타적인 행 상태 |

모든 행의 `analysis_ready`는 `no`다. 이는 각 행의 분류가 전부 틀렸다는 뜻이 아니라, **새 연구 범위와 시각 정렬이 아직 완료되지 않아 확정된 사건·대조군 데이터로 사용할 수 없다는 뜻**이다. `provisional_exclude`나 보류를 무신호로 자동 바꾸지 않는다. 정해진 검토 상태가 없는 추가 분류는 하지 않았다.

## 분류 기준 초안

1. 무역·관세, 연준·통화정책, 기업·산업, 재정·경기에 직접 관련된 구체 사안을 후보로 남긴다. 리트윗은 원작성자와 트럼프의 전달을 구분한다.
2. 경제성과 홍보·이미 알려진 사건의 반복·정치적 선거 주장은 구체적 신규 정책 발표와 별도 취급한다. 사실 여부와 사건 신규성은 별도 확인한다.
3. 경제 관련 단어가 있다는 이유만으로 정치·행사·방역·재난 글을 포함하지 않는다. 전체 의미를 알 수 없는 글은 보류한다.
4. 무역갈등 완화·고조·혼합·불명확은 무역 맥락을 확인해 별도 판정한다. 기존 `Positive`·`Negative`는 어조·경제성과·보호무역이 섞여 있으므로 기계적으로 새 갈등 방향에 대응하지 않는다. 통합본의 새 방향은 아직 모두 `unresolved`다.
5. 시장 수익률이나 트윗 이후에 공개된 정보는 게시 당시 사건의 포함 여부나 방향을 결정하는 데 사용하지 않는다.

## 애매한 사례

- **R25890 / R17252 — 철강 관세 효과 주장.** 기존에는 유사한 관세 찬사가 서로 다른 긍정·부정으로 분류됐다. 두 글은 관세의 철강산업 효과를 주장하지만 글 자체가 새로운 관세 발표라는 뜻은 아니다. 국내 산업에 대한 수혜 주장과 무역갈등 방향을 분리해야 한다.
- **R25291 — 연준 이사 지명.** Stephen Moore의 연준 인선 발표는 통화정책 관련 후보이나, 인선 자체로 금리 인하나 특정 산업 호재를 확정할 수 없다.
- **R23715 — ECB 전망 인용.** 유럽중앙은행의 금리 인하 전망을 인용한 글이다. 통화정책 관련성이 있지만 미국 연준 공격으로 분류하는 것은 부적절하다.
- **R18106 — ZTE 조건부 영업 재개.** 재개 허용과 벌금·보안 조건이 함께 있다. 제재 완화와 규제 강화 중 무엇을 기준으로 보느냐에 따라 해석이 달라져 단일 방향을 보류한다.
- **R13476 — 미중 관계 덕담.** 양국 관계를 강화하고 싶다는 언급만으로 무역협상 타결이나 구체적 진전을 확정할 수 없다.
- **R23622 — 농민 지지율.** 농민 지지율을 언급한 성과 홍보이며 본문만으로 실제 농가 지원의 신규 발표라고 보기 어렵다.
- **R60 — 브렉시트 리트윗.** 무역과 관련된 내용이지만 본문이 잘려 있어 원문과 전달 시점의 신규성을 확인해야 한다.
- **R14666 — 한미 공정경쟁.** 복원된 본문은 미국 노동자·기업·자동차 업계의 공정한 경쟁 여건에 관한 한미 정상의 논의를 언급한다. 경제·무역 관련 후보이지만 새 관세 부과·철회는 확인되지 않는다.
- **R15263 — 내각 인준 지연.** 복원된 본문은 내각 공석과 상원 인준 지연을 둘러싼 정치적 비판이므로 경제정책 연구 범위 밖으로 잠정 제외한다.
- **R4198 — 정부계약 배제 제안.** 연결 자료를 보지 않으면 대상 기업과 기술이 불명확하다. 정책 방향과 자산 영향을 단정하지 않는다.

개별 40행의 원문과 판단은 `generic_theme_manual_review_40.csv`, 이전 전체 판정은 원장 자체의 출처별 열에서 확인할 수 있다. 141건의 확장 참조 본문은 ID 대조·완전성·연결 매체 검증이 남아 있어 잠정 근거로만 보존했다. 89건의 이전 링크 텍스트와 추정 스레드는 원문 복원이나 답글 관계의 증명이 아니다.

## 앞으로 필요한 작업

후보와 기존 1,246행을 새 기준에 따라 개별 판정하고, 우선순위가 높은 보류 글의 원문·링크를 추가 확인해야 한다. 기존 원자료에서 저장 UTC와 ID 유래 시각이 충돌하는 사례 및 조기 폐장일을 검증한 뒤 거래일을 새로 계산한다. 통합본의 기존 거래일 열은 수정 전 값이다. 최종 검토 완료 후 사건과 무신호 대조군을 구성하고 보류 거래일의 포함·제외 민감도를 비교한다. 본 작업에서는 원본 분류와 시장 데이터, 기존 실증 결과를 수정하거나 재계산하지 않았다.

재생성: `python scripts/build_integrated_tweet_classification.py`. 원본 집합의 행 수, 상호 배타성, `raw_row`와 `audit_key`의 일대일 연결을 확인한다. 입력 파일 해시는 `integrated_classification_summary.json`에 저장한다.
